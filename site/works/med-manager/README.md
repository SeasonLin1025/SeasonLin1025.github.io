# 暖心管家 · 慢病用药智能助手

一款帮助慢性病患者管理用药计划、复诊提醒、健康档案的网页应用。

## ✨ 核心特性

### 🌟 全流程闭环
覆盖慢病管理 **问诊 → 开方 → 购药 → 用药 → 续方** 全链路

### 💊 用药计划管理
- 多种剂型支持（片剂/注射/口服液/外用）
- 灵活的服药时间设置（多时间点）
- 按疾病分类（高血压/糖尿病等）
- 用药注意事项与药物相互作用提示

### ✅ 智能服药打卡
- 时间轴式可视化
- 支持补打卡 / 漏服提示
- 完成全部任务有庆祝动画 🎉
- 7天周历切换查看

### ❤️ 健康档案
- 血压记录与趋势图
- 血糖记录与状态判断
- 基于数据的智能健康建议

### 🤖 AI 健康助手
- 常见用药问题解答
- 服药时间咨询
- 副作用提示
- 续方流程指引

### 📦 药箱与续方
- 库存可视化进度条
- 自动计算"还能用几天"
- ≤7天自动预警
- 一键在线续方

### 🏥 复诊提醒
- 倒计时提醒
- 就诊准备清单
- 多家医院/医生管理

### 👨‍👩‍👧 家人代管
- 邀请家人协助监督
- 漏服自动通知亲属

## 🚀 部署

本项目为零依赖纯静态文件，部署方式：

1. **Netlify Drop**（推荐 · 1分钟）：访问 https://app.netlify.com/drop ，把文件夹拖入
2. **GitHub Pages**：推到 GitHub 仓库 → Settings → Pages
3. **Vercel**：`npx vercel --prod`
4. **本地预览**：`python -m http.server 8080`

## 🎨 技术栈

纯 HTML + CSS + JavaScript（零依赖）+ localStorage 持久化
